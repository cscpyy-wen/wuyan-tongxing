# 无烟同行

一款免登录、离线使用的 Android 戒烟记录与行为支持 App。记录每一支烟，了解自己的习惯，在烟瘾来时得到及时帮助。

**[下载 Android 最新正式版](https://github.com/cscpyy-wen/wuyan-tongxing/releases/latest)** · [使用指南](docs/user-guide.md) · [更新内容](CHANGELOG.md)

适用于 **Android 15 及以上**。打开下载页后，在 **Assets（资源）** 中选择以 `.apk` 结尾的安装包；`Source code` 是源码，不是手机安装包。v34 无烟首页目前仍是发布候选，正式下载以该页面为准；[当前进展与发布条件](docs/releases/v34.md)。

## 安装与升级

1. 下载 APK 后，用手机文件管理器打开。手机提示时，仅为本次使用的浏览器或文件管理器允许“安装未知应用”。
2. 安装完成后打开“无烟同行”，按提示完成首次设置。可以关闭刚才授予的安装权限。
3. 已安装旧版时，先在“我的 → 导出副本”备份，再直接安装新版覆盖更新。**不要先卸载，也不要清除应用数据**。如果提示签名冲突，请停止安装并[反馈问题](https://github.com/cscpyy-wen/wuyan-tongxing/issues/new?template=bug.yml)。

手机无法下载时，可先在电脑下载，再通过数据线或手机互传发送到手机。更多说明见[安装与更新](docs/user-guide.md#安装与更新)。

## 开始使用

- **准备戒烟或正在减量：** 按首次设置选择直接戒断或限期减量，填写吸烟习惯、戒烟理由和戒烟日。
- **每次吸烟后：** 在“今日”点击“我吸了一支烟”，记录原因和烟瘾强度；误记后可以编辑或撤销。
- **烟瘾来时：** 打开 SOS，使用呼吸练习、烟瘾冲浪、换场景等支持工具。
- **每天回顾：** 在“记录”查看时间、支数和诱因，在“进展”查看计划和日常记录；核对后确认今日记录。
- **想更快记录：** 在“我的 → 快捷记录”添加桌面小组件或控制中心“记录一支”入口。

通知提醒可自行选择，拒绝通知权限也能正常记录和使用 SOS。小组件和锁屏下拉入口的可用方式取决于手机系统，见[快捷记录说明](docs/user-guide.md#快捷记录)。

## v34 候选新增：无烟首页

已经停止吸卷烟后，可从“今日 → 我已戒烟”设置最后一支烟的时间；新用户也可以在首次设置选择“已停止吸纸烟”。

无烟首页显示连续无烟时间、预计少吸支数、预计少花烟费、卷烟来源尼古丁粗估，以及带来源的健康时间线参考。点“调整”可修改起点、原日均支数、烟价和每包支数；之后若再次吸烟，照常记录即可。

这些数字依赖你的自报和记录，不是体内检测结果；健康参考不代表个人恢复进度。具体用法见[无烟首页指南](docs/user-guide.md#无烟首页v34-新增)。

用户已反馈本轮候选在 Xiaomi 15 Pro 真机使用无问题。这是该设备的用户实测反馈，不代表所有手机兼容、正式发布门禁通过或医学疗效验证。

## 数据与隐私

无需账号，健康记录保存在本机，不自动上传。官方 Android 版不需要联网权限，也没有广告或支付。

请定期在“我的 → 导出副本”备份。导出的文件未加密，含有完整记录，请妥善保管。卸载、清除数据或确认删除会移除本机记录；换手机时需要自行导出并恢复备份。详见[备份与隐私](docs/user-guide.md#备份与隐私)及[隐私数据地图](docs/privacy-data-map.md)。

本项目提供自我记录、行为支持和一般健康教育，不能替代医生或戒烟门诊，不提供诊断、处方或疗效保证。医学内容尚未完成具名医学审核；[内容证据与审核边界](docs/content-claims-matrix.md)可公开查阅。
