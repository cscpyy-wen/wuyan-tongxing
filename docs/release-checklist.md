# 正式微信发布门槛

内部测试完成不代表可以公开上线。下列条件全部通过后，才能建立正式发布候选版本。

## 主体与平台

- [ ] 已有适合服务类目的企业或个体主体和正式 AppID。
- [ ] 已在微信公众平台重新核验健康资讯/健康管理相关服务类目与材料。
- [ ] 小程序备案、域名 ICP 备案、HTTPS 证书和合法请求域名配置完成。
- [ ] 备案编号、隐私指引、用户协议和医学边界在产品内可见。
- [ ] 工作名称完成商标、重名和宣传用语核验。

## 医学与内容

- [ ] `docs/medical-review-checklist.md` 全部签署。
- [ ] 正式包不含 `DRAFT` 或 `EVIDENCE_VERIFIED` 状态的医学内容。
- [ ] 所有外部链接、热线、门诊信息和证据 URL 在发布日期前复核。

## 数据与安全

- [ ] 境内数据库、对象存储、日志、KMS 和备份已配置。
- [ ] 已完成个人信息保护影响评估并保存处理记录。
- [ ] 云同步、假名化统计和订阅消息分别单独同意。
- [ ] 管理员强认证、最小权限、审计、限流、告警、备份恢复和删除演练通过。
- [ ] 第三方 SDK 清单、目的、字段、保存期和接收方已披露；没有境外健康数据传输。

## 微信真实能力

- [ ] `wx.login`、会话刷新和退出在正式 AppID 下通过。
- [ ] 隐私接口、合法域名、存储上限和版本更新在开发者工具通过。
- [ ] 订阅消息模板、逐次授权、发送失败和应用内降级通过。
- [ ] 分享卡在 iOS 与 Android 微信真机通过且默认不泄露敏感信息。
- [ ] 体验版成员完成两条戒烟路径、SOS、离线、同步冲突和数据删除。

## 宣传边界

- [ ] 没有“保证成功”“临床验证有效”“提高 X 倍”等未经本产品前瞻性研究支持的表述。
- [ ] 没有把 WHO 指南、竞品研究或外部组合干预效果归因于本产品。
- [ ] 用户测试只报告可用性、理解度和完成率；疗效研究另行取得伦理审批并预注册。
