# 内容医学审核门禁

## 当前结论

全部内容是 `draft/internal` 循证草案。证据来源和表述边界已结构化，但尚未完成具名医学审核，不能进入公开生产渠道，也不能写成“医学审核通过”“临床验证”或任何成功率宣传。当前免登录网址只是显著标注草案状态的公开工程预览；任何人可访问这一事实不把它变成已审核的公开生产内容。

## 具名审核角色

1. 戒烟相关执业医师或具备相应资质的医学审核人：审药物、戒断、特殊人群、急症和健康主张。
2. 药师：审药物名称、批准与可及性、说明书边界和不良反应升级措辞。
3. 证据审核人：逐项核对原始来源、版本、适用人群、研究设计与局限。
4. 隐私/合规审核人：审敏感个人信息、单独同意、互联网诊疗边界和平台政策。
5. 内容发布人：只发布已具有完整审核记录和明确版本的内容。

同一人可以承担多个角色，但审核记录必须留下姓名、资质/职责、日期、内容版本和结论。

## 必审高风险内容

- `medication-01`…`medication-06`：所有药物名称、NRT 联合表述、特殊人群和转介边界。
- `faq-12`、`day-05`、`faq-02`：120/110/12356 的使用情境和措辞。
- `day-25`：健康时间线的每一个节点、来源和不确定性表达。
- `faq-06`：电子烟风险与产品不推荐边界。
- `followup-month-03/06/12`：7 日、30 日、连续戒断和未知值口径。
- 省级戒烟资源筛选与全国权威入口：机构、电话、服务时间和最近核验日期；如后续增加市级目录，必须逐城市建立并审核资源表，不能由省级入口推断。

## 单项审核清单

- [ ] 目标人群与证据人群一致；差异已明确说明。
- [ ] 主张可由 `evidenceIds` 对应来源直接支持，没有把相关性写成因果。
- [ ] 没有个体诊断、选药、剂量、处方、购买入口或疗效预测。
- [ ] 没有保证成功、具体个人恢复承诺或把框架称为临床验证。
- [ ] 药品名称和中国批准/可及性已按审核日核验。
- [ ] 急症、严重不良反应、自伤风险和未成年人边界清楚。
- [ ] 语言尊重自主、不羞辱，不把滑倒写成全部失败。
- [ ] 行动步骤可在预期场景安全执行，驾驶等特殊场景有明确提醒。
- [ ] 风险声明不会被折叠、付费墙或广告遮挡。
- [ ] 修改后的 `body` 仍不超过 180 个 Unicode 字符且自动校验通过。

## 状态门禁

当前包只允许 `draft/internal`。未来后台即使支持“证据核验→医学审核→发布→退役”，也必须满足：审核记录齐全、证据未过期、内容版本不可变、发布渠道明确、可回滚。任何内容被修改后回到草稿，不能沿用旧审核结论。
