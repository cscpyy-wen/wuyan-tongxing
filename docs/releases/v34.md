# Android v34：无烟生活首页（发布准备）

截至 2026-10-22，v34 仍未正式发布。可下载的正式版以 [GitHub Releases](https://github.com/cscpyy-wen/wuyan-tongxing/releases/latest) 为准。此页记录源码更新、使用方式和发布阻断，不是新版 APK 已通过全部检查的声明。

## 这次增加了什么

- 已经戒烟的人可以设置最后一支烟的日期和时间，首页直观看到连续无烟时间、少抽支数、少花烟费和阶段纪念。
- 原日均支数、每包烟价和每包支数都能在首页「调整」中修改，不改写原有记录。
- 健康时间线提供有来源的群体研究参考，不计算个人患癌概率或「恢复百分比」。尼古丁只作卷烟来源的粗估，不是体内检测。
- 首次使用增加「已停止吸纸烟」入口；已有用户可从「今日 → 我已戒烟」进入。
- 再次吸烟时，照常记录一支；连续计时重新开始，累计估算仍保留。误记可撤销。
- 修复大字号圆环重叠、设置页快速返回白屏、键盘日期选择和原生快捷记录冲突判断。

完整操作见[使用指南](../user-guide.md)。从旧版更新前应先导出备份，之后覆盖安装，不先卸载；正式 APK 发布前无需尝试从源码附件安装。

## 为什么还没有正式 APK

2026-10-22 的实时依赖扫描未通过既定发布门禁；详情见[依赖风险登记](../dependency-risk-register.md)。这与真机操作测试属于不同检查范围。源码可公开审查，但不能因此宣称安全审计通过。

正式发布仍需完成依赖修复、重新生成并审计供应链资料、完整发布门禁、准确提交的 GitHub CI，以及正式包签名／公开下载哈希核验。发布时本页会更新为实际完成状态；不会修改历史报告来抹掉失败记录。
