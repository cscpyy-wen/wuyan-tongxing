# Android v34：无烟生活首页

[下载 Android 正式版](https://github.com/cscpyy-wen/wuyan-tongxing/releases/latest) · [使用指南](../user-guide.md)。在 Assets 中选择 `.apk`，不要下载 Source code 当作安装包。适用于 Android 15 及以上。

## 这次增加了什么

- 已经戒烟的人可以设置最后一支烟的日期和时间，首页直观看到连续无烟时间、少抽支数、少花烟费和阶段纪念。
- 原日均支数、每包烟价和每包支数都能在首页「调整」中修改，不改写原有记录。
- 健康时间线提供有来源的群体研究参考，不计算个人患癌概率或「恢复百分比」。尼古丁只作卷烟来源的粗估，不是体内检测。
- 首次使用增加「已停止吸纸烟」入口；已有用户可从「今日 → 我已戒烟」进入。
- 再次吸烟时，照常记录一支；连续计时重新开始，累计估算仍保留。误记可撤销。
- 修复大字号圆环重叠、设置页快速返回白屏、键盘日期选择和原生快捷记录冲突判断。

从旧版更新前先在“我的 → 导出副本”备份，之后覆盖安装，不先卸载、不清除数据。已有用户安装新版后，可在“今日 → 我已戒烟”设置起点；不会自动猜测你最后一支烟的时间。
