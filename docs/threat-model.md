# 威胁模型（0.1 工程候选版）

本模型使用数据流和滥用场景检查设计，控制项参考 OWASP ASVS 5.0、OWASP MASVS 和最小权限原则；“参考”不表示取得认证或覆盖上述标准全部要求。

## 资产与信任边界

| 资产 | 边界 | 主要风险 |
| --- | --- | --- |
| 本机戒烟计划、记录与自报结局 | 浏览器/微信本地存储 | XSS、共享设备、恶意扩展、设备丢失、误删 |
| 可选同步密文与身份标识 | 客户端—API—数据库 | 越权、重放、载荷混淆、密钥复用、冲突静默覆盖 |
| 假名化统计 | 独立统计标识与事件入口 | 与 OpenID/IP/时间日志再关联、超范围字段 |
| 内容、规则与证据 | 内容后台—发布渠道—客户端 | 未审核内容误发布、回滚覆盖、规则注入 |
| 管理员会话与密钥 | 管理端—API—密钥系统 | 凭据填充、会话盗用、内部人员滥用、轮换中断 |
| 删除、提醒与后台队列 | API—队列表—Worker—微信 API | 非原子重复、漏删、死信无告警、第三方故障 |
| 构建与发布来源 | Git—CI—依赖源—Sites/微信 | 依赖投毒、秘密进入制品、dirty tree 发布、来源不可追溯 |

## 主要场景与现有控制

| 场景 | 当前控制 | 尚未关闭的风险/上线闸门 |
| --- | --- | --- |
| 未登录用户使用核心功能 | H5 不接 API；客户端静态扫描阻断登录、手机号和网络请求；可选同意默认关闭 | 本地存储不是硬件安全区；共享设备需用户主动删除站点数据 |
| 恶意脚本读取健康记录 | React 默认转义、无自由脚本规则；Worker-only 公网响应已实测哈希 CSP、`frame-ancestors 'none'`、`X-Frame-Options: DENY` 和最小权限策略 | Taro 当前仍需 `style-src 'unsafe-inline'` 兼容例外；微信 WebView、浏览器扩展和第三方运行时仍需真机验证与持续监测 |
| 同步重放或同 ID 换载荷 | UUID 幂等、严格对象 schema、请求大小限制、载荷指纹冲突检测 | 正式客户端尚未接线；PostgreSQL 并发与迁移需生产集成测试 |
| 跨用户读写/删除 | 鉴权主体约束、删除任务 owner proof、越权测试 | 正式身份密钥需拆分、KMS、`kid` 和双钥轮换；管理员需 MFA/SSO |
| 统计被重新识别 | 独立随机 ID、字段白名单、禁止 OpenID 联表 | CDN/API 访问日志仍含网络元数据；生产需入口/日志隔离与保留策略 |
| 未审核医学内容公开 | 草案渠道强制状态、界面显著标注、主张—证据矩阵 | 当前公开网址任何人可访问；具名医学审核前不能称为正式产品或宣传疗效 |
| 队列重复或永久失败 | 唯一约束、事务、有限重试和状态记录 | 生产必须增加 heartbeat、死信告警、删除 SLA 与人工处置台 |
| 供应链或发布篡改 | 锁文件、安装脚本白名单、固定 CI action、SBOM、依赖审计、构建预算 | 远端 CI、签名制品和 SLSA provenance 尚未实际产生，不能声称已达 SLSA 等级 |

## 滥用与危机边界

- 产品不诊断、不监测危机、不提供个体用药/剂量，不接受自由文本健康日记。
- 未成年人不保存问卷并退出成人路径。
- 急性胸痛、严重呼吸困难或自伤风险只转介人工紧急服务；号码和措辞必须由医学/法律审核后发布。
- 社区、私信、教练、支付、广告、现金奖励、CO 硬件、生成式 AI 和疗效预测不在本版本攻击面；任何新增都必须重新建模。

## 复核触发器

正式 AppID/手机号、真实同步或统计、生产云、第三方 SDK、医生/处方、支付、社区、定位、AI、疗效研究、数据跨境或宣传主张发生变化时，必须在合并前更新本模型并重新完成隐私影响评估和安全测试。
