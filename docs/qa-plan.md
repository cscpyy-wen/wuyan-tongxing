# 无烟同行 QA 计划

## 自动化范围与运行方式

H5 端到端测试使用 Playwright Chromium，在 `390 × 844` 手机视口、`zh-CN`、`Asia/Shanghai` 下串行运行。每个测试使用独立浏览器上下文，并在首次设置前清空本地存储。Playwright 先执行 Taro H5 生产构建，再由 `scripts/serve-h5.mjs` 静态托管最终产物；不依赖 Taro watch server。

```powershell
pnpm test:e2e:install
pnpm test:e2e
```

失败时保留 trace、截图和视频，HTML 报告写入 `playwright-report/`。最后一次完整结果见 `docs/test-report.md`。

## 自动化验收矩阵

| 验收主题 | 自动化场景 | 已验证边界 |
| --- | --- | --- |
| 成人边界 | 未成年人选择退出 | 不生成 baseline、plan 或敏感健康信息同意；刷新仍进入首次设置 |
| 两条路径 | 直接戒断、限期减量、再次尝试 | 本地计划类型正确；减量 3 阶段可调且单调递减、到期归零；旧计划归档且累计进展保留 |
| 主导航 | 今日、记录、进展、我的 | tab 路由和标题正确；每个主页面都有全局 SOS |
| 烟瘾急救 | 一击进入并完成呼吸练习 | 打开即开始、无需登录提示、`aria-live`、完成记录持久化 |
| 离线 | 在线初始化后断网重载 | Service Worker 接管并缓存全部 H5 静态包；断网重载今日页后可首次打开 SOS |
| 记录与滑倒 | 冷启动、0 支打卡、吸烟记录、滑倒恢复 | 冷启动不覆盖当日值；已完成任务和打卡不清零；新增滑倒与支数记录 |
| 长期随访 | 3/6/12 月入口、3 月到期提交 | 入口存在；3 月全漏答以 `null/未知` 保存；注明自报、未经生化验证 |
| 伙伴支持 | 四种模板预览 | 用户主动切换预览；DOM 卡片不含支数、药物、戒烟日期或账号字段 |
| 隐私默认值 | 订阅、同步、统计 | 三项默认关闭，应用内任务默认开启；主流程不调用微信身份 |
| 数据权利 | 本机导出、删除、失败恢复 | 导出前提示剪贴板风险并清理兼容副本；删除回读确认，失败保留原状态且不误报成功 |
| 本地状态韧性 | 非法日期、损坏对象、超大数组 | 严格拒绝或安全恢复到首次设置；全局错误页不上传错误内容且保留离线 SOS |
| 无障碍 | 四主页面与 SOS | 无横向溢出；目标至少 44×44；焦点不被固定元素遮挡；SOS 位置一致；axe WCAG 2.0/2.1/2.2 A/AA 无 violation；Enter 可激活 |

## 自动化尚不能证明的事项

- 浏览器从未访问过站点时的纯离线冷启动；没有预缓存就不存在可执行代码。
- 6/12 月随访的自然时间推进、所有已回答组合和长期通知到达率。
- 系统大字号、完整焦点顺序、读屏器朗读质量和认知可理解性；axe 不能替代人工辅助技术测试。
- 真正的微信分享面板、通讯录权限、OpenID、订阅发送、模板失败、合法域名、体验版和生产云。
- 备份 30 天自然清除、境内生产 KMS/PostgreSQL 和多设备真实同步冲突。
- 低端 Android、iPhone、弱网、后台恢复和杀进程重启。

## 微信开发者工具与真机人工验收

1. 在微信开发者工具中记录导入目录、基础库、编译时间、控制台零错误截图和构建版本。
2. 至少一台低端 Android 和一台 iPhone 走完两条首次设置路径，确认未成年人不留下问卷字段。
3. 断网前打开小程序，再从四个主页面进入 SOS；另行记录冷启动离线的真实平台边界。
4. 正式订阅消息逐次授权；拒绝、模板无效和网络失败都必须降级为应用内今日任务。
5. 四类分享卡在真实分享面板逐项截图，不得带吸烟量、药物、戒烟日期、连续天数、OpenID 或其他身份信息。
6. 分别测试撤回同步、统计、订阅和敏感信息同意，以及本机/云端导出和删除。
7. 使用系统大字号、VoiceOver/TalkBack 或平台读屏器逐页检查标签、顺序、状态变化和错误提示。

## 发布闸门

- 自动化全部通过且没有跳过用例；失败必须关联缺陷、修复版本和复测证据。
- 当前微信身份、订阅、生产同步和微信分享只能标为模拟/降级验证。
- 所有医学内容完成证据核验与具名医学审核后，才允许离开内部草案渠道。
- 真机、大字号、读屏、弱网和低性能人工记录完成前，不宣称全面满足无障碍或平台验收。
