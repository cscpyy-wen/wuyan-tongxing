# 医学内容审核清单

当前内容全部为内部测试用循证草案。进入正式运营渠道或作为已审核产品宣传前，具名持证医学审核人需逐项完成以下检查；公开免登录工程预览不等于通过本门禁。

- [ ] 每项健康或疗效主张均关联可访问的一手指南、系统综述或正式 RCT。
- [ ] 没有把竞品营销、工具包收录或硬件许可写成产品疗效认证。
- [ ] 依赖程度仅称为“提示”，没有形成医学诊断。
- [ ] 药物内容符合中国当前说明书、可及性和监管状态。
- [ ] 没有自动选药、剂量、疗程、相互作用判断、处方或购买入口。
- [ ] 孕哺期、重大躯体/精神疾病治疗和明显不良反应均转介医生或药师。
- [ ] 120、12356、戒烟热线和门诊入口已在发布日期前人工拨测或核验。
- [ ] 电子烟没有被描述为安全产品或默认戒烟方案。
- [ ] 健康时间线使用群体层面的保守表述，不保证个人器官恢复时间。
- [ ] 所有结局均注明用户自报、未经生化验证，不用于产品疗效宣传。
- [ ] 文案不羞辱、不恐吓，不把一次滑倒描述为失败或清零。
- [ ] 审核人、资质、审核日期、内容版本和修改意见已写入发布审计。

只有审核覆盖率达到 100%，内容状态才能进入 `MEDICALLY_APPROVED`。医学审核不能替代主体、备案、隐私和微信类目审核。
