# 隐私与数据地图

本文首先描述当前 Android 个人版的实际实现；实验端和后端设计单列在文末。戒烟记录按敏感健康信息保护。本文件是工程数据说明，不替代正式法律意见或各分发渠道需要的隐私政策。

## Android：本机记录与主动导出

Android App 无需登录，核心功能不连接 API。Android 清单没有 `INTERNET` 权限，APK 校验脚本也会拒绝申请该权限的包；当前没有云同步、成效统计上传或微信身份交换。页面、内容、规则和无烟首页计算随安装包在本机运行。

首次使用要求成人确认和本机处理敏感健康信息的主动同意。拒绝同意不建立戒烟档案；用户可在“我的”撤回同意并删除应用内数据。每日提醒另行开启，在系统需要时请求通知权限；拒绝通知不影响记录与应用内今日任务。

| 数据 | 保存与访问范围 | 用途 |
|---|---|---|
| 首次流程状态与健康数据同意 | 应用本机档案；不保存身份证件或生日 | 限定成人流程并控制本机处理 |
| 历史日均支数、晨起第一支、既往尝试、原因和诱因、每包价格 | 应用本机档案 | 生成规则化计划及原始基线 |
| 当前与归档计划、任务完成情况 | 应用本机档案 | 保存尝试历史和进度 |
| 吸烟、烟瘾、滑倒、日终确认和自报随访 | 应用本机档案；按记录类型保存时间、支数、结构化原因或强度等 | 复盘、进度及自报指标；不是生化验证 |
| v34 `quitJourney` | 应用本机档案，随 JSON 副本导出和恢复 | 保存当前尝试 ID、最后一支时间 `startedAt`、原日均支数、每包价格、每包支数及主动确认时间 `confirmedAt` |
| 无烟时长、累计少抽、少花烟费及健康参考展示 | 由本机档案和设备时间计算 | 自报估算与一般科普；不产生个人检测结果或患病概率 |
| 桌面小组件与控制中心快捷记录 | 应用私有队列、当前计划与当日支数摘要；由本机组件读取 | 在未打开主界面时记录，再由客户端归并和去重 |
| 提醒开关、小时和系统通知安排 | 应用本机设置及 Android 通知系统 | 用户主动开启的本地每日提醒 |
| 恢复辅助数据 | 应用私有目录内的最后有效副本、待处理快捷记录、隔离/损坏证据、导入或删除事务状态 | 在中断、损坏或写入失败后恢复，避免静默丢失或重复记录 |
| 内容、规则与证据版本 | 随 APK 打包 | 内容追溯，不包含用户档案 |

`quitJourney` 用于无烟首页估算，不替换原始基线，也不会自动补写过去的每日确认。修改参数、编辑或删除吸烟记录后按原始记录重算；缺少准确时间的历史汇总会保留估算边界。旧 v33 档案没有此字段时保持未配置状态。计算口径见 [无烟首页证据矩阵](quit-dashboard-evidence.md)。

当前 Android 流程不要求手机号、头像、昵称、通讯录、精确位置、相册、麦克风、伙伴身份或聊天内容；不提供自由文本健康日记。

## 存储、备份与删除

- 核心档案由 Android 原生持久化桥接写入 `getNoBackupFilesDir()` 下的私有目录；正常读写有格式、容量和写入结果校验，并保留最后有效副本。兼容升级路径还会处理旧 WebView 本地数据。这些机制改善持久性，不构成加密保证。
- Manifest 设置 `allowBackup=false`、`fullBackupContent=false`，数据提取规则排除云备份和设备迁移。用户应主动导出副本，不能依赖系统自动恢复。
- 当前本机 JSON 与导出的 JSON **未做应用层加密**。操作系统的设备保护与应用隔离不能被表述为本项目实现了加密数据库或端到端加密。
- “我的 → 导出副本”经确认打开 Android 系统“另存为”，由用户选择文件名与位置。副本包含计划、记录、设置、`quitJourney` 及必要的快捷记录恢复信息。恢复模式的副本还可能保留无法读取数据的原始证据；即使采用 Base64 编码，也不是加密或脱敏。
- 如果在系统文件选择器中选择云盘等位置，所选服务可能上传或同步文件；这是用户选择的文件服务行为，不能以 APK 无网络权限推断副本始终留在设备上。备份文件不得放进公开 Issue、仓库、截图或演示。
- 恢复前校验文件，并显示摘要供用户确认；确认后替换当前档案，提醒保持关闭，可在“我的”重新开启。恢复不是合并多个独立档案。
- “删除所有数据”或撤回健康记录同意会清除应用内档案和相关恢复数据，并尝试取消本地提醒；系统暂时拒绝取消时会在重启后再次协调。未完成数据删除会保留待续状态，重启后继续处理。该操作不会删除用户此前另存、分享或上传的文件。
- 数据保留到用户主动删除、系统清除应用数据或卸载为止；没有 Android 云端副本或自动到期备份承诺。清除或卸载前应确认需要的副本已可用。CSV 尚未实现。

桌面小组件可显示当日支数，能看到屏幕的人可能看到这些信息；通知是否显示在锁屏上由系统设置决定。用户可移除组件、调整锁屏通知或关闭提醒。

## 日志与反馈红线

客户端、服务端、测试快照、公开 Issue 和提交历史不得包含真实健康记录、问卷答案、导出内容、完整敏感请求体、token、OpenID、签名材料或设备标识符。复现使用人工构造的数据；日志只保留必要的脱敏错误信息，生产服务错误仅记录请求 ID、路由、状态码和脱敏错误码。安全漏洞和意外泄露使用 [私密漏洞报告](https://github.com/cscpyy-wen/wuyan-tongxing/security/advisories/new)，详见 [安全政策](../SECURITY.md)。

## 实验端与后端：不属于当前 Android 服务

仓库保留 H5、微信、HarmonyOS 和 API/Worker 适配与契约测试。实验客户端中的云同步、假名化成效统计和微信订阅状态默认关闭，当前没有接通真实上传或授权；Android 不显示这些云能力开关。API 的同步、身份、统计和删除实现不代表已经向 Android 用户提供服务。

后续若接通正式服务，仍须独立同意云同步、成效统计和微信订阅；拒绝可选能力不得阻断本地核心功能。统计事件只允许打开应用、完成首次计划、完成任务、开始/完成 SOS、提交随访等白名单，属性限阶段、内容 ID、规则版本和布尔/枚举结果；禁止逐次吸烟日志、具体戒烟日、自由文本、药物信息、危机选择、OpenID 和伙伴信息，统计标识不得与 OpenID 联表。

实验 API 有敏感字段加密和删除队列代码，但这不适用于 Android 本地 JSON，也不能说明正式云备份、密钥管理或运维已投入使用。假名化原始事件 18 个月、生产备份最长 30 天等是后端保留策略目标，不能当作现有 Android 数据处理事实。正式接线前须验证数据字段、独立同意、加密与密钥管理、访问控制、删除与备份恢复，并更新实际供应商、保存期和适用隐私文本。PGlite 在生产环境下的拒绝启动门禁必须保留，详见 [技术架构](architecture.md)。

正式服务设计还要求：云端删除请求生效后立即阻断在线查询，以幂等任务清理主库；不从备份恢复已删除账号供日常使用。只有不可逆聚合指标才可按独立策略长期保存，不能把假名化原始事件视为已匿名化数据。

H5 工程预览访问需要网络。其客户端记录保存在浏览器本地，但托管/CDN 仍会处理 IP、请求时间、User-Agent 等普通网络元数据，并可能设置基础设施安全 Cookie；这与产品内成效统计不同，也不属于 Android APK 的运行数据流。
