# 无烟同行使用指南

[下载 Android 最新正式版](https://github.com/cscpyy-wen/wuyan-tongxing/releases/latest) · [返回首页](../README.md) · [更新内容](../CHANGELOG.md)

无烟同行适用于 Android 15 及以上设备，无需注册或登录。核心功能可离线使用。

本指南包含 v34 无烟首页的说明；v34 目前仍是发布候选。若安装的是 v33，不会看到“我已戒烟”和无烟首页入口，正式发布状态以下载页为准。

## 安装与更新

### 第一次安装

1. 打开上方下载页，在 **Assets（资源）** 中选择以 `.apk` 结尾的文件。不要下载 `Source code`，它不能作为 App 安装。
2. 下载后，用手机文件管理器打开 APK。若系统要求，允许当前文件来源“安装未知应用”，完成安装后可以关闭该授权。
3. 打开“无烟同行”，阅读使用说明和本机健康记录说明，再完成首次设置。

手机无法直接下载时，可以先在电脑下载，再用数据线或手机互传发送到手机。下载页也提供校验文件；希望核验文件来源的用户可查看[开发指南中的安装包核验](development.md#安装包核验)。

### 从旧版升级

1. 在旧版“我的 → 导出副本”保存一份备份，并确认能在文件管理器中找到它。
2. 下载最新正式 APK，直接覆盖安装现有官方版本。**不要先卸载，不要清除数据。**
3. 打开 App，检查原来的计划和记录是否还在。

如果提示签名冲突，先停止安装并反馈，不要通过卸载旧版绕过。开发测试版与官方版是独立应用，其数据不会自动合并；不要把更旧的安装包强制覆盖新版。

## 首次设置

按实际情况回答成年、吸烟状态和本机健康记录同意项。

- 还在吸卷烟：填写日常吸烟习惯、戒烟理由和常见诱因，选择“直接戒断”或“限期减量”，设定戒烟日。
- 已停止吸卷烟（v34 新增）：选择“已停止吸纸烟”，填写戒烟前的习惯，再设置最后一支烟的日期和时间。
- 从备份继续：在首次设置中选择“恢复备份”，按提示选择自己保存的备份文件。

通知为可选功能。拒绝通知权限不会阻止记录、查看进展或使用 SOS。

## 每天记录与回顾

吸烟后，在“今日”点击“我吸了一支烟”，选择原因和 1–5 级烟瘾强度。App 自动记录时间，之后可在“记录”中编辑或撤销误记。

“记录”展示当天支数、时间、间隔及诱因；“进展”用于查看计划和日常记录。一天结束前，核对逐支记录，再点“确认今日 … 支”。无烟首页的自报起点不会自动补写过去每一天的确认。

烟瘾上来时，点击 SOS，选择呼吸练习、烟瘾冲浪、换场景、查看戒烟理由等支持工具。这些内容可离线打开。

## 无烟首页（v34 新增）

### 开启与调整

1. 老用户打开“今日 → 我已戒烟”；已停止吸烟的新用户可从首次设置进入。
2. 选择最后一支烟的日期和时间，按实际情况确认“此后没有再吸烟”。已有准确的逐支记录时，可以选择“使用最近记录的准确时间”。
3. 核对“每天支数”“每包价格”“每包支数”，点击“保存并查看成就”。

日期与时间按北京时间填写。需要修改时，点无烟首页右上角“调整”。更改起点需要重新确认；仅调整烟价或其他估算参数不会改写历史吸烟记录。

### 怎样理解首页数字

| 显示内容 | 计算含义 |
| --- | --- |
| 连续无烟时间 | 根据设定起点和之后的吸烟记录计算，每满 24 小时计一天 |
| 少吸卷烟 | 按起点以来的时间与原日均支数估算，再扣除期间已记录支数，最低为 0 |
| 少花烟费 | 预计少吸支数乘以每支烟的价格；未扣除戒烟用品等其他开支 |
| 少摄入卷烟尼古丁 | 使用一般吸收量假设作粗估，不是个人体内含量、排出量或精确吸收量，也不计算贴片、口香糖、电子烟等来源 |
| 健康时间线 | 研究中常见的时间段和健康变化参考，不是个人检测结果或恢复进度 |

计算依赖自报参数和记录完整性。首页可展开计算说明和来源；也可查阅[指标证据说明](quit-dashboard-evidence.md)。

### 如果又吸了一支

照常记录这支烟。连续计时会重新开始，累计少吸、少花烟费等估算会更新；原有历史记录和任务不会因此全部清空。误记时，可以编辑或撤销。

如果页面提示设备时间异常，先检查手机日期、时间和时区。不要通过删除记录或改动起点来绕过提示。

## 快捷记录

完成首次设置后，打开“我的 → 快捷记录”。

- **桌面小组件：** 点击“桌面小组件”，在系统面板中确认添加。小组件显示今日支数和距上一支的计时，点击整张卡片即可记录一支。
- **控制中心：** 点击“锁屏下拉入口”，按系统提示加入“记录一支”。没有弹出面板时，可在控制中心编辑页手动添加。

如果小米桌面没有弹出添加面板，可尝试“桌面双指捏合 → 添加小部件 → 搜索 → 安卓小部件 → 无烟同行 → 记录一支烟”；菜单名称可能因系统版本不同而变化。

快捷记录只保存时间，不要求填写原因和烟瘾强度。回到 App 后可以只改时间，也可以补全详情。只有手机允许在锁屏下拉控制中心时，该入口才可在锁屏使用；深度休眠时，小组件跨日刷新可能延迟。

小组件数字可能被能看到你屏幕的人看到。无烟首页出现后，桌面小组件仍用于记录吸烟，不会变成无烟成就展示卡片。

## 备份与隐私

在“我的 → 导出副本”保存备份；需要恢复时，选择“我的 → 恢复备份”，按提示选择文件。换手机前先在旧手机导出，再将备份传到新手机恢复。

恢复备份会替换当前 App 内的数据，不是把两个档案自动合并。建议先导出当前副本，再进行恢复。

记录只保存在本机，不自动上传，也没有账号云端副本。系统备份与自动设备迁移默认关闭；卸载、清除应用数据、删除所有数据或撤回健康记录同意都会清除应用内记录。已经另行导出的文件不会随之删除。

导出的 JSON 文件未加密，可能包含完整健康记录，请保存在你信任的位置，不要提交到公开 Issue。更多说明见[隐私数据地图](privacy-data-map.md)。

## 遇到问题

- **安装失败：** 确认手机是 Android 15 或以上，文件下载完整，并来自本仓库 Release。签名冲突时保留旧 App 和数据，先反馈。
- **找不到无烟首页：** 查看安装版本；该功能从 v34 开始提供，v33 不包含此入口。
- **估算与预期不同：** 在“调整”核对时间、日均支数、烟价和每包支数，再核对吸烟记录是否完整。
- **小组件没有及时更新：** 打开 App 检查最新记录，必要时移除并重新添加小组件。系统休眠和桌面策略可能影响刷新。

通过[问题反馈表单](https://github.com/cscpyy-wen/wuyan-tongxing/issues/new?template=bug.yml)说明 App 版本、手机型号、系统版本和复现步骤。截图请先遮住私人信息，不要附上真实记录、完整备份或凭据；安全问题请走[私密报告渠道](../SECURITY.md)。
