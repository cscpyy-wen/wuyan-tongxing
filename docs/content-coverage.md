## 每项内容的固定字段

每项均包含 `id`、`kind`、`order`、`version`、`status`、`channel`、`title`、`goal`、`mechanisms`、`body`、`steps`、`action`、`riskStatement` 和 `evidenceIds`。正文主体不超过 180 个 Unicode 字符，步骤和风险声明不计入该限制。

机制名称采用 BCT Taxonomy、COM-B/BCW、CBT、ACT、实施意图及 5A 等可解释术语。机制标签只描述设计，不是疗效证明。

## 产品边界

- 药物内容只到通用信息、说明书提醒和就诊问题清单；没有个体选药、排序、剂量、处方或购买入口。
- 健康时间线只表达人群科普，不预测个人在某天一定出现的变化。
- 连续无烟在最后一支烟后重算；累计少吸、完成任务、历史尝试和有效策略不清零。
- 随访漏答保存为“未知”，不自动归为戒烟或复吸；所有结局均标为“用户自报、未经生化验证”。
- SOS 不登录、不联网也能开始；伙伴分享不读取通讯录，默认不含吸烟量、药物或戒烟日期。
- 未满 18 岁不进入成人内容。胸痛、严重呼吸困难等急症指向 120，人身危险指向 110，心理援助可指向 12356；应用不判断或监测危机。
