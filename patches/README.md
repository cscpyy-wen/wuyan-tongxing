# Third-party dependency patches

These patches preserve the upstream package names and versions. They are not upstream releases.

- `braces@3.0.3.patch` modifies MIT-licensed braces; retain [LICENSE-braces](LICENSE-braces).
- `http-cache-semantics@4.3.0.patch` modifies the BSD-2-Clause-licensed package; retain [LICENSE-http-cache-semantics](LICENSE-http-cache-semantics).

Original upstream context and derived modifications retain their respective upstream license. The offline braces test embeds unmodified upstream test fixtures with their MIT notice included in the test file. See [provenance, review and validation](../docs/security-patches/README.md).
